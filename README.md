This repository contains the R code used for the analysis of urinary tract infections (UTIs) among adults admitted to acute public hospitals in the Republic of Ireland between 2020 and 2024.
The analysis was conducted using routinely collected Hospital In-patient Enquiry (HIPE) data.
The R script includes code for: Data preparation and cohort selection,
classification of Primary community-acquired UTI (Primary CA-UTI),
secondary community-acquired UTI (Secondary CA-UTI), 
and hospital-acquired UTI (HA-UTI),
descriptive and comparative analyses,
clinical outcomes, multivariable logistic regression, figures and tables.
Software: the analysis was conducted using R
Data availability: the patient-level HIPE dataset is not included in this repository
the repository contains analysis code only.
